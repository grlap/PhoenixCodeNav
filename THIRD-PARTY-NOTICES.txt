.NET runtime files in self-contained distributions
---------------------------------------------------

A framework-dependent PhoenixCodeNav publish does not redistribute the .NET
host runtime. A self-contained publish does. For a self-contained publish,
MSBuild copies the LICENSE and THIRD-PARTY-NOTICES files from every exact
runtime pack resolved by the .NET SDK into legal/runtime-packs/<package-id>/.
Those files are runtime-version-specific and are deliberately sourced from the
resolved packages instead of being frozen in this repository.

On Windows, Microsoft states that coreclr.dll and .NET runtimes embedded in a
single-file executable are governed by the Microsoft .NET Library License.
That separate license is shipped as legal/Microsoft-DotNet-Library-License.txt
for Windows single-file self-contained output. It does not change the
Apache-2.0 license of PhoenixCodeNav source.

Sources:
https://github.com/dotnet/core/blob/main/license-information.md
https://github.com/dotnet/core/blob/main/license-information-windows.md
